# NSEdge

A small Windows companion for the Sony DualSense Edge.

See your active onboard profile, saved profile name and battery level. Get profile-change and battery popups, choose your lighting colours, and keep the app out of the way in the tray.

**[Download NSEdge](https://github.com/eggntoast/NSEdge/releases)**

Extract the ZIP and run `NSEdge.exe`. Windows 11 x64 only. .NET is included. The app is unsigned.

### Before you start

DS4Windows is not required. If you use it, profile monitoring and battery features still work, but NSEdge lighting is not currently supported alongside standard DS4Windows.

Lighting and Bluetooth disconnect are experimental. Battery levels are approximate. Fn + Square profile detection is incomplete.

This repository is for downloads. Development source is maintained separately.
